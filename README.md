# Juju Turn In

A World of Warcraft Classic Era addon that automates Juju turn-ins with Witch Doctor Mau'ari.

## Features

- **Smart Mode:** Automatically turns in Jujus from your bags, prioritizing the Juju you have the most of.
- **Favorite Juju:** When Smart Mode is disabled, turns in your selected favorite Juju.
- **Automatic mode:** Leave all Jujus checked to let the addon handle turn-ins automatically.

## Installation

1. Download the latest release from [CurseForge](https://www.curseforge.com/wow/addons/juju-turn-in).
2. Extract the `JujuTurnIn` folder into your WoW Classic Era `Interface/AddOns` directory.
3. Restart the game or reload the UI.

## Usage

Configure the addon in-game and choose whether to use Smart Mode or a Favorite Juju.

## Compatibility

- World of Warcraft Classic Era
